Every beginner developer asks "where can I host this for free?" - and bookmarks the answer. Direct follow-on from the free LLM APIs audience: same people, simpler list.

## Frontend
| Tool | What it does |
| --- | --- |
| [Vercel](https://vercel.com/) | Deploy frontend sites in minutes |
| [Netlify](https://www.netlify.com/) | Static sites with forms and functions |
| [Cloudflare Pages](https://pages.cloudflare.com/) | Fast static hosting on a global network |
| [GitHub Pages](https://pages.github.com/) | Host static sites from GitHub |
| [Firebase Hosting](https://firebase.google.com/products/hosting) | Fast static hosting, free tier |


## Backend and APIs
| Tool | What it does |
| --- | --- |
| [Render](https://render.com/) | Web services with a free tier |
| [Fly.io](https://fly.io/) | Run small apps close to users |
| [Railway](https://railway.app/) | Deploy backends from GitHub easily |
| [Cloudflare Workers](https://workers.cloudflare.com/) | Serverless functions at the edge |
| [Deno Deploy](https://deno.com/deploy) | Deploy JavaScript at the edge |
| [Google Cloud Run](https://cloud.google.com/run) | Run containers serverlessly, free tier |
| [Zeabur](https://zeabur.com/) | Deploy apps from GitHub easily |
| [Appwrite](https://appwrite.io/) | Open-source backend, auth, database |
| [Spacefast](https://spacefast.com/) | Publish AI-built sites and apps, free personal plan with no card | 
| [Cloady](https://cloady.com/docs/free-tier) | App and database hosting with a free workspace (0.5 vCPU, 1 GB RAM, 5 GB SSD), no card required and no end date |

## Contributing
See CONTRIBUTING.md. The short version: fork this repo, add your entry as one line in the right table, open a pull request. Rules: the service must have a permanent free tier, no credit card required to start. No trial-only hosting. One entry per service.
