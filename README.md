# awesome-free-hosting
> Free hosting for your side projects. Curated, simple, and free to use — one line per entry.
- [Vercel](https://vercel.com/) — Deploy frontend sites in minutes
- [Netlify](https://www.netlify.com/) — Static sites with forms and functions
- [Cloudflare Pages](https://pages.cloudflare.com/) — Fast static hosting on a global network
- [Render](https://render.com/) — Web services with a free tier
- [Fly.io](https://fly.io/) — Run small apps close to users
- [Railway](https://railway.app/) — Deploy backends from GitHub easily
- [Supabase](https://supabase.com/) — Postgres, auth and storage, free to start
- [Neon](https://neon.tech/) — Serverless Postgres with a free tier
- [Upstash](https://upstash.com/) — Serverless Redis and Kafka
